# HASHlib/FHT-512
A custom hashing function designed for maximum flexibity, including a user-generated initialization-vector, user-generated OPCODE sequence, and a user input (to hash).

# Usage
Simply enter in a 32 character or more IV (initialization vector), a sequence of OPCODES (numbers 1-9), and your desired input.
The hash function generates a 512-bit character output.
